# YouTube Learning Quiz Extension

This Chrome extension enhances the YouTube viewing experience by making it more interactive and educational. It periodically pauses a playing YouTube video at a user-defined interval and displays a multiple-choice question as an overlay. The question is generated by the Google Gemini AI based on the content of the video's transcript.

## Features

- **AI-Powered Question Generation:** Connects to the Google Gemini API to generate relevant quiz questions.
- **Interactive Quiz Overlay:** Pauses the video and displays a clean quiz UI directly over the YouTube player.
- **Configurable Settings:** Includes an options page to set your Gemini API key and the quiz interval.
- **Automatic Transcript Handling:** Programmatically opens, reads, and closes the YouTube transcript panel to gather text for the AI.
- **Enable/Disable Toggle:** A simple popup allows you to easily toggle the quiz functionality on or off.

## How to Install and Run

To use this extension, follow these steps:

### 1. Load the Extension in Chrome

1.  Download or clone this repository to your local machine.
2.  Open the Google Chrome browser and navigate to `chrome://extensions`.
3.  In the top-right corner, enable **"Developer mode"** by clicking the toggle switch.
4.  A new menu will appear. Click on the **"Load unpacked"** button.
5.  In the file selection dialog, navigate to the directory where you saved this project and select it.
6.  The "YouTube Learning Quiz" extension should now appear in your list of extensions.

### 2. Configure the Extension

Before the extension can work, you need to provide your Google Gemini API key.

1.  Find the "YouTube Learning Quiz" extension in your `chrome://extensions` list and click on the **"Details"** button.
2.  Select **"Extension options"**.
3.  On the settings page:
    -   Enter your **Google Gemini API Key** in the first field.
    -   Set your desired **Quiz Interval** in minutes (e.g., `5` for a quiz every 5 minutes).
4.  Click the **"Save"** button.

### 3. Using the Extension

1.  Navigate to any YouTube video that has a transcript available.
2.  Start playing the video.
3.  The extension will automatically pause the video and show a quiz after your configured time interval has passed.
4.  Answer the question. If you are correct, the video will resume. If you are incorrect, an explanation will be shown before you can continue.
5.  You can click the extension's icon in the Chrome toolbar at any time to open a popup and toggle the quiz feature on or off.

That's it! Enjoy a more interactive learning experience on YouTube.
